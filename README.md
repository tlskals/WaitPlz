# 🚍 기사님, 잠시만요! (WaitPlz)

> **출퇴근 직장인을 위한 스마트 대중교통 비서 & 하차 알람 앱**

불규칙한 버스 배차 간격, 복잡한 환승, 졸음으로 인한 하차역 놓침을 해결하기 위해 개발된 크로스플랫폼 모바일 어플리케이션입니다.

---

## ✨ 핵심 기능

1. **🚍 출퇴근 0클릭 버스 대시보드**
   - 현재 위치와 무관하게 내가 탈 버스와 정류장 도착 정보 즉시 확인
   - 오전(출근) / 오후(퇴근) 시간대별 자동 루틴 전환
   - ⚠️ 연속 배차(1~2정거장 간격으로 겹쳐 오는 버스) 감지 알림
   - 15초 실시간 자동 갱신 및 잔여 좌석 수 표기

2. **🚇 지하철 실시간 도착 & 지연/시위 공지**
   - 호선별 열차 실시간 도착 정보 및 현재 열차 위치
   - 시위, 사고, 신호장애 등으로 인한 긴급 지연 공지 피드 제공

3. **⏰ "기사님, 잠시만요!" 스마트 하차 알람 (핵심 기능)**
   - 광역버스나 지하철에서 잠들어도 목적지 반경(300m~2,000m) 진입 시 화면이 꺼져 있어도 강력한 진동 및 사운드 알람 발송
   - 원터치 토글스위치(ON/OFF)로 출퇴근 루틴 관리
   - 카드 내 레이더 맵 뷰 및 `((•)) 반경 1km` 뱃지 시각화

4. **⚙️ 설정 & 환경설정**
   - 진동 세기, 기본 하차 반경, 출퇴근 자동 전환 시간대 설정
   - 공공데이터 라이선스 및 오픈소스 라이선스 표기

---

## 🎨 디자인 시스템
- **테마**: 다크 챠콜/블랙 (`#121212`, `#1C1C1E`) + 시그니처 네온 라임 (`#D4F843`)
- **UI/UX**: 출퇴근 피로도를 낮추는 고대비 폰트, 원터치 토글, 레이더 맵 뷰

---

## 🛠️ 기술 스택
- **Framework / Language**: Flutter 3.38.5 / Dart 3.10.4
- **State Management**: Riverpod 3.x (Notifier Pattern)
- **Local Storage**: `shared_preferences`
- **Notifications & Vibration**: `flutter_local_notifications`, `vibration`
- **Location & Maps**: `geolocator`, `flutter_naver_map`
- **Network**: `dio`, `xml`
- **Data Source**: 국토교통부(TAGO), 서울특별시(TOPIS), 서울교통공사, 코레일
